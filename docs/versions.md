# 两个版本如何阅读

| 分支 | 内容 | 用途 |
|---|---|---|
| main | 当前ECU-A六任务FreeRTOS＋ECU-B裸机仪表 | 编译、故障实验、作品展示 |
| baseline/baremetal | 早期双节点裸机源码 | 看周期调度、比较职责演进 |

裸机源码来源：作者旧私有仓库 `stm32-bms-freertos-portfolio` 的 `baseline/baremetal`，提交 `baae12b7cfc09599bbbcb3eadd16f0ad4a9fd991`。公开快照保留业务源码，第三方依赖单独安装；旧私有仓库历史不变。

该快照早于后续多轮裸机可靠性改造，不是切入FreeRTOS前最后一天的完整快照。主线还增加了统一故障生命周期、CLI、注入实验、日志V2、CAN Alive/CRC、健康监控等能力。因此比较时不能把全部差异归因于RTOS。

早期版已知电压编码/显示比例问题和演示性充放电状态不代表主线能力；早期分支文档会保留这些边界，不伪造修复历史。

建议阅读顺序：main的系统图→Sensor与故障矩阵→注入实验→任务与IPC→再回看裸机调度。这样先理解业务，再看调度方式为什么变化。
